# Global Computer Science Core

## Purpose

The Global Computer Science Core is an original curriculum architecture for Next Gen Learning Hub. It is not a copy of any university degree and does not claim institutional endorsement or accreditation.

The structure was synthesized from recurring patterns in globally recognized computer-science programs, including:

- MIT EECS — foundation subjects, advanced CS tracks, laboratories, projects, algorithms, systems, software, AI and theory.
  - https://www.eecs.mit.edu/academics/undergraduate-programs/curriculum/
  - https://www.eecs.mit.edu/academics/undergraduate-programs/curriculum/6-3-computer-science-and-engineering/
- IIT Delhi CSE — mathematics/science and engineering foundations, discrete mathematics, data structures, architecture, operating systems, networks, algorithms, theory, cryptography and capstone work.
  - https://curriculum.iitd.ac.in/view_program.php?program_code=CS1
- IIT Bombay CSE — broad CSE foundation with focus areas in AI, computing systems, security and theoretical computer science, plus independent project options.
  - https://www.cse.iitb.ac.in/academics/programme/btech
- NPTEL / IIT course ecosystem — rigorous public courses covering algorithms, OS, architecture, databases, networks, theory, distributed systems, AI and related subjects.
  - https://nptel.ac.in/courses
- Stanford CS — mathematics, science and engineering fundamentals; CS core; systems/theory/AI and other depth tracks; senior project work.
  - https://www.cs.stanford.edu/bs-degree-requirements
- Carnegie Mellon SCS — mathematical foundations, imperative and functional programming, data structures and algorithms, computer systems, theoretical CS, AI and project/elective depth.
  - https://www.cs.cmu.edu/education/undergraduate
- UC Berkeley CS/EECS — programming, data structures, discrete mathematics/probability, machine structures and broad upper-division CS depth.
  - https://engineering.berkeley.edu/academics/undergraduate-programs/electrical-engineering-computer-sciences/

## Design principles

1. Foundations before frameworks.
2. Mathematics is part of computing, not an optional appendix.
3. Programming must lead to abstraction, testing and software construction.
4. Data structures and algorithms require correctness and complexity reasoning.
5. Systems must connect architecture, operating systems and networks.
6. Theory establishes what can and cannot be computed efficiently.
7. Databases are studied as systems, not only as SQL syntax.
8. AI comes after probability, linear algebra, algorithms and systems foundations.
9. Human-computer interaction and security are core engineering concerns.
10. Every phase ends in an evidence-based mastery gate.
11. Advanced study culminates in an integrative capstone.
12. Planned curriculum is never counted as completed learning.

## Curriculum sequence

### Phase 1 — Mathematical foundations
- Calculus for Computing
- Linear Algebra for Computing
- Discrete Mathematics
- Probability & Statistics for Computing

**Mastery gate:** solve proof, modeling and probability problems without relying on memorized formulas.

### Phase 2 — Programming and software construction
- Python for Practical Problem Solving
- Programming Languages
- Software Engineering

**Mastery gate:** build, test, debug and explain a medium-sized program with explicit contracts.

### Phase 3 — Data structures, algorithms and theory
- Data Structures & Algorithms
- Theory of Computation

**Mastery gate:** design an algorithm, justify correctness and analyze time and space complexity.

### Phase 4 — Computer systems
- Computer Architecture
- Operating Systems
- Computer Networks

**Mastery gate:** trace a program through CPU, memory, OS and network layers and diagnose a systems failure.

### Phase 5 — Data and information systems
- Database Systems
- SQL
- Data Analytics

**Mastery gate:** design a schema, justify an index/query plan and produce a reproducible analysis.

### Phase 6 — Intelligent, human and secure computing
- Machine Learning Engineering
- AI & LLM Engineering
- Human-Computer Interaction
- Cybersecurity

**Mastery gate:** build and evaluate a system using model, user and security evidence.

### Phase 7 — Advanced engineering depth
- Distributed Systems
- System Design
- DevOps

**Mastery gate:** defend architecture trade-offs under latency, failure, consistency and operational constraints.

### Phase 8 — Capstone and research practice
- Computer Science Capstone

**Mastery gate:** deliver a working artifact, evaluation evidence, limitations, a technical report and an oral defense.

## What this project intentionally does differently from a degree

Next Gen Learning Hub is self-paced and browser-first. It does not reproduce university credit hours, examinations, admissions, grading policy, accreditation or institutional certification.

Instead, it borrows the strongest structural ideas: prerequisite depth, academic breadth, laboratories, proofs, systems thinking, independent projects, evaluation and technical communication.
